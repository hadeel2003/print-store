# Print Store

موقع متجر برينت ستور لمنتجات التخرج

## المنتجات

- بروشات أكليريك - 30 جنيه
- ميداليات أكليريك - 30 جنيه
- استيكات - 15 جنيه
- جورنال - 30 جنيه
- بروشات أكليريك حفر - 30 جنيه
- بورد الصور - 400 جنيه

## كيفية التعديل

### لتغيير أسعار المنتجات:
افتح `script.js` وعدّل سعر المنتج:

```javascript
const products = [
  { name: "اسم المنتج", price: 100, image: "product-1.jpg" },
];
```

### لإضافة صور:
1. ضع الصور في مجلد `images/`
2. استخدم نفس اسم الملف في `script.js`

مثال:
- صورة: `images/product-1.jpg`
- في الكود: `image: "product-1.jpg"`

## التصميم

- ألوان: برتقالي وزهري
- خلفية فاتحة وأنيقة
- متوافق مع الهواتف الذكية
- بطاقات منتجات جميلة مع تأثير عند المرور عليها
